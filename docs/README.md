# Documentation Directory

Welcome to the documentation folder for the Autonomous AI Creator project. This directory hosts all architecture diagrams, specifications, API guides, and process documentation.

## Directory Structure

- `/docs/architecture.md` - Technical stack, agent architecture, and data flows.
- `/docs/api_reference.md` - API endpoints, request/response models, and error handling.
- `/docs/database_schema.md` - Schema diagrams and relationship descriptions.
- `/docs/getting_started.md` - Detailed installation and development instructions.
